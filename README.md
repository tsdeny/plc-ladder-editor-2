## 🚀 GitHub Pages Kurulum

### 1. Icon'ları Hazırla

İki icon gerekli:
- `icons/icon-192.png` (192x192)
- `icons/icon-512.png` (512x512)

Online generator: https://realfavicongenerator.net/

### 2. GitHub'a Yükle

1. Repository oluştur: `plc-ladder-editor`
2. **PUBLIC** seç
3. Tüm dosyaları yükle
4. Settings → Pages → Branch: main → Save

### 3. Test Et

URL: `https://USERNAME.github.io/plc-ladder-editor/`

iOS/Android:
1. Safari/Chrome'da aç
2. "Add to Home Screen"
3. ✅ App gibi çalışır!
